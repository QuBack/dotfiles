# Проверки Windows-установщика

Проверки выполняются без установки программ на рабочем компьютере.

1. Скрипт разбирается Windows PowerShell 5.1 и PowerShell 7.
2. Меню, список программ и режим предварительного просмотра работают без WinGet.
3. Выбранные программы устанавливаются в порядке зависимостей: Node.js с npm перед Codex и Claude Code.
4. Уже установленная программа пропускается. Повторный запуск безопасен.
5. Ошибка одной установки не скрывается и не останавливает независимые программы.
6. Ошибка зависимости блокирует зависимую программу.
7. Неуспешное скачивание не получает статус «Скачано».
8. Статус «Скачано» сохраняется между запусками и проверяет наличие и SHA256 файлов.
9. Удалённый или изменённый файл сбрасывает статус скачивания.
10. Режим DryRun не скачивает, не устанавливает и не создаёт рабочие каталоги.
11. Имена неизвестных программ и несовместимые параметры отклоняются.
12. Автоматический режим возвращает код ошибки, если операция завершилась неуспешно.
13. Для обоих CLI используются правильные npm-пакеты и проверяются их команды.
14. Node.js без npm или старее 22 требует подготовки Node.js LTS.
15. Сохранённый старый EXE Claude не используется как npm-архив.
16. VLC скачивается и устанавливается через пакет VideoLAN.VLC.
17. Пункт NVIDIA открывает официальный подбор драйверов и получает статус
    «Manual», а не ложный статус успешной установки драйвера.
18. На компьютере без NVIDIA пункт пропускается. Ошибка определения оборудования
    показывает необходимость ручного подбора, а не отсутствие NVIDIA.
19. DryRun для NVIDIA не открывает браузер. Автоматический режим возвращает код
    2 при необходимости ручного выбора драйвера.

Живая проверка на чистой Windows: WinGet bootstrap, реальное скачивание каждого
пакета, UAC, установка, повторный запуск, доступность codex/claude в новом
терминале. Это отдельная проверка: автоматические тесты её не заменяют.

## Выполнено 30 сентября 2026 года

- 41 локальная проверка прошла в Windows PowerShell 5.1 и PowerShell 7.
- `-List` и `-All -DryRun` проверены с настоящим реестром и PATH компьютера.
- Меню проверено в терминале: открытие, стрелки, пробел, просмотр плана,
  возврат в список, выход.
- Скачивание, установка программ и восстановление WinGet на этом компьютере
  не запускались.
