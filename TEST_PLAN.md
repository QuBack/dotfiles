# Проверки Windows-установщика

Проверки выполняются без установки программ на рабочем компьютере.

1. Скрипт разбирается Windows PowerShell 5.1 и PowerShell 7.
2. Меню, список программ и режим предварительного просмотра работают без WinGet.
3. Выбранные программы устанавливаются в порядке зависимостей: Node.js с npm перед Codex и Claude Code.
4. Уже установленная программа пропускается. Повторный запуск безопасен.
5. Ошибка одной установки не скрывается и не останавливает независимые программы.
6. Ошибка зависимости блокирует зависимую программу.
7. Неуспешное скачивание не получает статус «Скачано».
8. Статус «Скачано» сохраняется между запусками и проверяет наличие и SHA256 файлов.
9. Удалённый или изменённый файл сбрасывает статус скачивания.
10. Режим DryRun не скачивает, не устанавливает и не создаёт рабочие каталоги.
11. Имена неизвестных программ и несовместимые параметры отклоняются.
12. Автоматический режим возвращает код ошибки, если операция завершилась неуспешно.
13. Для обоих CLI используются правильные npm-пакеты и проверяются их команды.
14. Node.js без npm или старее 22 требует подготовки Node.js LTS.
15. Сохранённый старый EXE Claude не используется как npm-архив.
16. VLC скачивается и устанавливается через пакет VideoLAN.VLC.
17. Пункт NVIDIA открывает официальный подбор драйверов и получает статус
    «Manual», а не ложный статус успешной установки драйвера.
18. На компьютере без NVIDIA пункт пропускается. Ошибка определения оборудования
    показывает необходимость ручного подбора, а не отсутствие NVIDIA.
19. DryRun для NVIDIA не открывает браузер. Автоматический режим возвращает код
    2 при необходимости ручного выбора драйвера.
20. Enter и пробел на программе переключают отметку без запуска установки.
21. «Установить выбранное» передаёт только отмеченные программы в порядке
    каталога. Пустой выбор не запускает операцию и показывает подсказку.
22. «Установить всё» передаёт весь каталог независимо от отметок.
23. Стрелки перемещают курсор между действиями, программами и выходом.
    Enter на «Выход» и Esc в любой строке закрывают меню.
24. Пробел на действии и удалённые буквенные команды не запускают установку.
25. Windows Terminal и PowerShell 7 Preview используют отдельные точные пакеты
    WinGet без фиксации версии; оба включены в `-All`.
26. Terminal определяется по MSIX-пакету Microsoft.WindowsTerminal, Preview
    PowerShell — по Microsoft.PowerShellPreview или MSI-записи с preview/rc.
    Стабильный PowerShell и Terminal Preview не подменяют выбранные каналы.
27. Кэш MSIX-статусов обновляется после установки. Если Appx недоступен,
    сохраняется проверка MSI через реестр.
28. Запуск через `powershell.exe -File` принимает список `-Apps` через запятую.
29. Chrome устанавливается через Google.Chrome, стабильный Chrome определяется
    по записи установленного приложения, Chrome Beta не подменяет его.
30. Настройка Terminal выполняется после установки и при пропуске уже
    установленных программ. Скачивание, DryRun и выбор только Chrome не меняют
    настройки запуска.
31. JSONC-комментарии, строки с URL, существующие профили и остальные настройки
    сохраняются. Меняются только корневые поля запуска; неверный JSONC и
    дублирующиеся параметры отклоняются.
32. Профиль ссылается на отдельный исполняемый файл Preview, работает до первого
    открытия Terminal. Отключённый источник фрагмента не выдаётся за успех.
33. Перед изменениями создаются резервные копии. Повторный запуск идемпотентен.
    Частичная ошибка записи делегирования восстанавливает прежние значения.
34. Системное делегирование ограничено поддерживаемыми Windows. Ошибка настройки
    видна отдельно и возвращает код ошибки в автоматическом режиме.
35. Codex и Claude имеют независимые пункты приложения и CLI. Можно выбрать
    только приложение, только CLI или оба варианта; `-All` включает все четыре.
    Прежние ключи `codex` и `claude` продолжают выбирать CLI.
36. Codex-приложение устанавливается через точный Store ID `9PLM9XGG6VKS`
    с источником `msstore`; Claude Desktop — через `Anthropic.Claude`, Steam —
    через `Valve.Steam` с источником `winget`. Chrome остаётся в каталоге.
37. Приложения не добавляют Node.js/npm в зависимости. Установленный CLI
    не подменяет приложение; MSIX/реестровая запись приложения не подменяет CLI.
    Codex определяется по `OpenAI.Codex`, Claude — по MSIX `Claude` или реестру.
    Steam определяется по точной записи `Steam`, а не по игре или SteamVR.
38. Ошибка Node.js блокирует CLI, но не установку приложений и Steam.
39. `-Download` для Codex-приложения возвращает `Manual` с подсказкой выбрать
    установку, не запускает загрузку Store и не создаёт квитанцию «Скачано».
    Остальные выбранные загрузки продолжаются; DryRun остаётся без изменений.
40. GitHub CLI (`gh`) включён в меню и `-All`, использует точный пакет
    `GitHub.cli` из источника `winget`, определяется по `gh.exe` или записи
    `GitHub CLI`. Git и GitHub Desktop не подменяют его. Выбор gh не добавляет
    Node.js/npm и не запускает вход в аккаунт.
41. AmneziaVPN при установке и скачивании открывает официальный сайт и
    возвращает `Manual`, без обращения к WinGet и квитанции «Скачано».
    Старый кэш WinGet игнорируется; уже установленная Amnezia пропускается.
    DryRun не открывает браузер; автоматический режим возвращает код 2.
42. Выбор Amnezia вместе с GitHub CLI и Chrome не мешает другим операциям.
    Ошибка открытия сайта получает `Error`, независимые установки продолжаются.
43. Telegram Desktop доступен в меню, `-List` и `-All` с ключом `telegram`.
    Используется пакет `Telegram.TelegramDesktop` из источника `winget`.
    Установленное приложение определяется по записи `Telegram Desktop` в реестре;
    выбор Telegram не добавляет зависимостей. `-DryRun` не запускает установщик.
44. PowerToys доступен в меню, `-List` и `-All` с ключом `powertoys`.
    Используется пакет `Microsoft.PowerToys` из источника `winget` без фиксации
    версии. Уже установленный PowerToys пропускается; дополнительные программы
    из каталога в план не добавляются. `-DryRun` не запускает установщик.
45. WinRAR доступен в меню, `-List` и `-All` с ключом `winrar`.
    Используется пакет `RARLab.WinRAR` из источника `winget` без фиксации версии.
    Уже установленный WinRAR определяется по записи Windows и пропускается;
    дополнительных зависимостей из каталога нет. `-DryRun` не запускает установщик.
46. WSL 2 (`wsl`) и Docker Desktop (`docker`) входят в каталог и `-All`.
    Docker добавляет WSL перед собой; зависимость не дублируется. Готовый WSL
    и установленный Docker пропускаются при повторном запуске.
47. WSL определяется по пакету MSI/MSIX и версии не ниже 2.1.5. Встроенный
    `wsl.exe` без пакета не запускается при проверке статуса. Для готовности
    нужны служба `vmcompute`, активный гипервизор и успешный `wsl --status`.
48. WSL запрашивает повышение прав только при установке/обновлении. Отдельный
    дистрибутив не устанавливается. Код 3010 или неготовые компоненты получают
    `Manual`, откладывают Docker и дают код завершения 2; остальные программы
    продолжаются. Ошибка WSL даёт `Error`, Docker — `Blocked`, код завершения 1.
49. Docker устанавливается точным пакетом `Docker.DockerDesktop` с движком
    `wsl-2`. CLI и Compose не считаются Docker Desktop. `-Download` не включает
    компоненты Windows; `-Apps docker -Download` не добавляет WSL. Просмотр
    плана не создаёт файлы, не запускает установщики и не запрашивает UAC.
50. uv (`uv`) и Poetry (`poetry`) доступны в меню, `-List` и `-All`.
    uv использует точный пакет `astral-sh.uv` и не добавляет Python в план.
    Poetry добавляет одну зависимость uv перед собой; уже установленный Poetry
    пропускается независимо от способа установки, без установки uv.
51. Poetry устанавливается через `uv tool install --python 3.13 poetry`,
    затем `uv tool update-shell` и обновление PATH. Команда `poetry --version`
    проверяет результат. Отсутствие uv, сбой установки или отсутствие команды
    Poetry после установки не должны получать успешный статус.
52. Ошибка uv блокирует только зависимый Poetry; независимые программы
    продолжаются. Повторный запуск пропускает установленные инструменты.
53. `-Download` для Poetry даёт `Manual` и код 2, не создаёт квитанцию и не
    обращается к WinGet для Poetry. Остальные выбранные загрузки продолжаются.
    DryRun поясняет ограничения без установки, скачивания Python или записи PATH.

Живая проверка на чистой Windows: WinGet bootstrap, реальное скачивание каждого
пакета, UAC, установка, повторный запуск, доступность codex/claude в новом
терминале. Это отдельная проверка: автоматические тесты её не заменяют.

- Меню проверено в терминале: открытие, стрелки, пробел, просмотр плана,
  возврат в список, выход.
- Скачивание, установка программ и восстановление WinGet на этом компьютере
  не запускались.
